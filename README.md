# Useful Websites — V3

A static, multilingual directory of genuinely useful, interesting and accessible websites.

## Included
- 67 curated websites across 8 categories
- English, Portuguese, Spanish, French and German
- Search across names, URLs, categories, tags, descriptions and search synonyms in all supported languages
- Category filters
- Multilingual tags
- Surprise Me with consecutive-repeat prevention and filter awareness
- Persistent language and light/dark theme
- Responsive layout
- Independent-directory disclaimer
- Google Analytics 4 with measurement ID `G-K3CVC964BK`
- Privacy-conscious custom events: website opens, category filters, Surprise Me, language/theme changes and search usage; search text itself is not sent

## Files
- `index.html` — page structure and Google Analytics tag
- `style.css` — responsive visual design
- `data.js` — curated site data, translations, categories and tags
- `script.js` — filtering, search, language/theme controls, Surprise Me and analytics events

## GitHub Pages
1. Create a GitHub repository.
2. Upload the five files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the branch containing the files (usually `main`) and folder `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

No server, database, PHP or build step is required.

## Analytics
The site includes the Google tag for measurement ID `G-K3CVC964BK`. Google Analytics may take some time to begin showing data after publication.

The custom events deliberately avoid sending the visitor's search query to Google.

## Editorial policy
“Free” does not automatically mean a website belongs in Useful Websites. The directory prioritizes genuinely useful, interesting, distinctive, low-friction, educational, privacy-oriented, clever or interactive websites.
